# 🌐 Система переводов (i18n) — RU/EN/ZH

> **Версия:** 1.0 · **Дата:** 2026-07-28

---

## 📋 Кратко

NayTea — трёхъязычная: RU (по умолчанию), EN, ZH. Архитектура как в iznaki.ru.

**URL-структура:**
| Язык | URL | `<html lang>` | Cookie |
|---|---|---|---|
| 🇷🇺 Русский | `naytea.ru/` | `ru` | `lang=ru` |
| 🇬🇧 English | `naytea.ru/en/...` | `en` | `lang=en` |
| 🇨🇳 中文 | `naytea.ru/zh/...` | `zh` | `lang=zh` |

## 🛠️ Как добавить новый текст

### Вариант 1: Через словарь (рекомендуется для повторяющихся текстов)

**Шаг 1:** Добавить ключ в `translations.ts`:
```typescript
'mySection.title': {
  ru: 'Мой заголовок',
  en: 'My title',
  zh: '我的标题',
},
```

**Шаг 2:** В client component:
```tsx
const { t } = useLanguage()
return <h1>{t('mySection.title')}</h1>
```

**Шаг 3:** В server component:
```tsx
import { getLang } from '@/lib/i18n/server'
import { t } from '@/lib/i18n/translations'

export default async function Page() {
  const lang = await getLang()
  return <h1>{t('mySection.title', lang)}</h1>
}
```

### Вариант 2: Через L() helper (для уникальных текстов)

Если текст встречается 1 раз — нет смысла в словарь:

```tsx
const { lang } = useLanguage()
const L = (zh: string, en: string, ru: string) =>
  lang === 'zh' ? zh : lang === 'en' ? en : ru

return <p>{L('中文文本', 'English text', 'Русский текст')}</p>
```

## 🔀 Переключатель языков

В шапке (`page.tsx`):
```tsx
<button onClick={() => switchLang('ru')}>RU</button>
<button onClick={() => switchLang('en')}>EN</button>
<button onClick={() => switchLang('zh')}>中</button>
```

`switchLang(newLang)`:
1. Устанавливает cookie `lang=newLang` (1 год)
2. Формирует новый URL: для RU — `/`, для EN — `/en/...`, для ZH — `/zh/...`
3. `window.location.href = newPath` — перезагружает страницу

## ⚙️ Как работает middleware

```typescript
// src/middleware.ts
export function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  // /zh/... → rewrite на /... + cookie lang=zh
  if (pathname === '/zh' || pathname.startsWith('/zh/')) {
    const newPath = pathname.replace(/^\/zh/, '') || '/';
    const url = request.nextUrl.clone();
    url.pathname = newPath;
    const response = NextResponse.rewrite(url);
    response.cookies.set('lang', 'zh', { path: '/', maxAge: 31536000, sameSite: 'lax' });
    return response;
  }

  // /en/... → аналогично
  if (pathname === '/en' || pathname.startsWith('/en/')) { /* ... */ }

  // Для обычных URL — НЕ делаем авто-редирект.
  // Пользователь сам выбирает язык через switchLang().
  return NextResponse.next();
}

export const config = {
  matcher: [
    '/((?!api|_next/static|_next/image|favicon\\.ico|robots\\.txt|sitemap|google|og-image|.*\\.(?:svg|jpg|jpeg|webp|png|ico|xml|txt|html|mp4|css|js|woff2?|ttf|map)$).*)',
  ],
};
```

**Важно:** middleware НЕ делает авто-редирект с `/` на `/en`. Это предотвращает цикл: пользователь сменил язык на RU → middleware видит старый cookie `lang=en` и редиректит обратно.

## 📝 Правила

1. **Любой текст — в 3 языках.** Хардкод запрещён.
2. **Новый ключ — ОБЯЗАТЕЛЬНО все 3 языка** (ru, en, zh).
3. **Не дублировать контакты в переводах** — они в `data.ts` (если будет) или напрямую в компоненте.
4. **SEO metadata** — через `generateMetadata()` с 3 языками.
5. **Проверка перед деплоем:**
   - [ ] Новый ключ имеет ru/en/zh
   - [ ] Нет хардкод-текстов в JSX
   - [ ] Проверены `/en/...` и `/zh/...` версии

## 🐛 Частые проблемы

### Переключатель не работает обратно на RU
**Причина:** баг с пустым `newPath` (был в ранней версии).
**Решение:** в `useLanguage.ts` проверь:
```typescript
if (newLang === 'ru') {
  newPath = cleanPath; // '/' или '/search'
} else {
  newPath = `${newPrefix}${cleanPath === '/' ? '' : cleanPath}`;
}
```

### На /en/ страница рендерится на русском
**Причина:** client component, SSR использует `DEFAULT_LANG='ru'`.
**Решение:** `useLanguage()` синхронизирует с cookie в `useEffect`. Текст переключится после hydration. Для SSR можно передать `initialLang` из layout.
